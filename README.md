# NetworkWalks CTF Challenge – John the Ripper

## Project Overview

This repository documents my hands-on Capture The Flag (CTF)
experience on NetworkWalks.

The challenge provided an opportunity to practice password
security concepts using John the Ripper and a wordlist-based
approach.

This project is part of my continuous learning journey in
Cybersecurity.

## Objective

The objective was to complete the assigned CTF challenge,
work with password hashes, and successfully capture the flag.

## Tools Used

- Kali Linux
- John the Ripper
- Hash Calculator
- rockyou.txt Wordlist
- NetworkWalks CTF Platform

## Methodology

The practical exercise involved the following activities:

1. Used Hash Calculator to generate a hash from a password.
2. Used John the Ripper for password recovery testing.
3. Used the rockyou.txt wordlist during the exercise.
4. Successfully completed the assigned NetworkWalks challenge.
5. Retrieved the CTF flag.
